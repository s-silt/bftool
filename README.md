# 归档备份工具 (bftool)

> SSD → 机械盘，**按文件夹**安全归档，SHA256 三重校验，绝不误删，可中断续传。
> **新手友好桌面版 `bftool-gui.exe`**(浅色扁平 GUI，7 视图)+ 命令行 `bftool.exe`，**下载即用**，无任何外部依赖。

## 这是给谁用的

你在 SSD 上做项目（视频、图片、文档、代码……），做完一个，想把整个文件夹**完整复制**到一块机械硬盘冷存；一块盘写满了换下一块（自动编号「备份1、备份2、备份3…」）；过半年到一年定期复查，发现坏道立刻知道；**绝不希望源被误删**，也不想做去重/加密那么重的方案。

如果这描述符合你，这个工具就是给你的。

如果你需要的是：增量快照、加密、云同步、去重 → 请看 [restic](https://github.com/restic/restic)、[rustic](https://github.com/rustic-rs/rustic)、[conserve](https://github.com/sourcefrog/conserve)，那是别的问题域。

## 快速上手（桌面版 GUI）

新手推荐直接用图形界面，全程点选，不用敲一行命令。下面 7 步走完就能用。

### 1. 下载

到 [Releases](https://github.com/s-silt/bftool/releases) 下载 `bftool-x86_64-pc-windows-msvc.zip`，解压得到：

- **`bftool-gui.exe`** — 桌面版（本文主角，双击即用）
- `bftool.exe` — 命令行版（进阶，详见 [other.md](other.md)）
- `bftool.toml.example`、`README.md`、`other.md`、`LICENSE`

放到任意目录（比如 `C:\Tools\bftool\`）即可。

> **不需要安装 Visual C++ Redistributable**：单 `.exe` 文件静态链接 CRT，无任何外部 `.dll` 依赖。界面中文依赖系统已装中文字体（Windows 默认有微软雅黑）。

### 2. 双击 `bftool-gui.exe`

打开就是**仪表盘**——左侧栏切换 7 个视图，底部常驻状态栏（运行状态 + 已用时间 + 取消按钮）。首次打开还没配置，先去「设置」。

### 3. 首次设置（「设置」视图，约 30 秒）

点选三个根目录，告诉工具东西放哪：

| 目录 | 放什么 |
|---|---|
| **待备份** | 做完、准备归档的项目文件夹丢这里 |
| **已备份** | 校验通过后，源会被**移动**到这里（不删，等你自己处理） |
| **备份系统** | 全局索引/名单等系统文件 |

点「保存」即可。配置默认存到 `%APPDATA%\bftool\config.toml`。

### 4. 初始化一块空盘（「初始化」视图）

插上一块**空的**机械硬盘（NTFS 格式）。视图会列出候选盘并做防呆（系统盘 / 资料库盘 / 非空盘会拦），选中目标盘点初始化。工具会自动取下一个编号（`备份1`、`备份2`…），在盘里建好 `\项目\`、`\本盘信息\` 并写说明文件。

### 5. 备份（「备份」视图）

把做完的项目文件夹挪到第 3 步设的「待备份」目录下，然后：

1. 点 **「🔍 演练 / 刷新计划」**——只列出会做什么，不动文件，先看计划对不对。
2. 确认无误，点 **「▶ 正式备份」**——实时进度条 + 日志，随时可「✕ 取消」（当前项目完成后停，不会写坏）。

每个项目会经过：稳定性检测 → 体积检查 → 完整复制 → SHA256 三重校验 → 事务式提交。中途取消或断电，下次再「正式备份」会从断点续。

### 6. 复查（「复查」视图，防坏道）

> **备份不等于"复制完了"**。*backups aren't useful unless you've tested them.*（借自 [rsure](https://github.com/d3zd3z/rsure)）跑过复查才算"已验证的备份"，**建议每 6–12 个月一次**。

选一块盘点复查，会重算每个项目的 SHA256 跟清单比对，报告损坏 / 缺失 / 多余文件。也可以「📁 选文件夹 / 📄 选文件」只复查单个目标。复查对盘**只读**，封盘的盘也能查。

### 7. 找项目 / 换盘

- **找以前的项目**：去「查找」视图输关键词，告诉你它在哪块「备份N」、盘内路径。
- **盘写满了**：工具自动封盘并提示，取下贴标签离线收好，插下一块空盘，回第 4 步初始化继续。

## 七个视图能干什么

| 视图 | 作用 |
|---|---|
| **仪表盘** | 当前盘 / 待备份数 / 容量已用 / 最近复查一屏总览；每盘容量横条 + 复查健康环；三大按钮直达备份/复查/初始化 |
| **备份** | 演练预览计划 → 正式备份；实时进度 + 日志 + 取消（项目边界生效）；高级设置（限量/危险开关）折叠 |
| **复查** | 选盘整盘复查，或「📁 选文件夹 / 📄 选文件」只复查**单个目标**的哈希 |
| **初始化** | 列出候选盘 + 防呆（系统盘/资料库/非空盘），点选初始化；`--force` 藏在二次确认后 |
| **查找** | 关键词在全局索引查项目位置（哪块备份N、盘内路径），支持多机汇总 |
| **盘列表** | 列出已识别的备份盘 |
| **设置** | **点选目录**改三大根目录与参数 → 校验 → 保存（默认 `%APPDATA%`） |

> GUI 与 CLI **共用同一套 core 引擎和配置**，行为完全一致 —— GUI 绝不通过 shell 调 `bftool.exe`，而是直接调用引擎。

## 安全要点（请务必看）

1. **单份不算真备份**。每个项目默认只在一块盘上有一份；那块盘坏了就没了。**真正可靠是 3-2-1 —— 至少两份介质 + 一份异地/云**。重要资料请跑两套盘或加云盘。
2. **气隙防勒索**。盘封盘后**拔下、离线收好**，勒索病毒碰不到离线的盘。
3. **定期复查**。每 6–12 个月一次复查。
4. **总索引留份**。`备份系统\备份索引名单.csv` 建议另存一份到云盘。
5. **写满即拔**。当前在写的盘以外都拔下，避免误写。
6. **绝不删源**。校验通过后源被**移动**到「已备份」，永远等你自己决定删不删；从不镜像（不会"源删了把备份也删"）。
